🛡️ Security & Data Transparency

Consent-Driven Location: WaySafe never runs invisible background GPS tracking when the tab or browser is closed. Coordinates are acquired and persisted strictly with your active confirmation.

All API requests are authenticated with cryptographic Supabase session tokens. Ownership of trips and check-ins is strictly enforced through server authorization and PostgreSQL Row-Level Security (RLS).
